
# Crypto Price Predictor

## 📌 Project Overview
Crypto Price Predictor is a machine learning-based application that predicts cryptocurrency prices using historical market data. This project helps users analyze trends and estimate future prices.

## 🚀 Features
- Cryptocurrency price prediction
- Data preprocessing and analysis
- Machine Learning model
- User-friendly interface

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML
- CSS
- JavaScript

## 👩‍💻 Team Project
This project was developed as a team project. I contributed to the development, testing, and integration of the application.
